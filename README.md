# 🍒 Вишнёвое приключение ко дню рождения

Пиксельная игра-подарок: главная комната с тремя дверями, в каждой комнате — персонаж, диалог и мини-игра, после неё — катсцена. Когда пройдены все три, начинается финал: три девочки, торт со свечкой и салют.

| Комната | Персонаж | Мини-игра |
|---|---|---|
| Кухня | Аня | Готовим торт: ингредиенты → замес → выпечка → украшение |
| Гардеробная | Лиза | Одевашка (та же механика, что в CottsugDRESSUP) |
| Музыкальная | Соня | Ритм-игра на клавишах `S D K L` |

Комнаты открываются по очереди. Закрытая дверь показывает текст «Персонаж не дома» (у каждой двери текст свой, он меняется в редакторе).

Управление: `WASD` / стрелки — ходить, `E` — действие, мышкой можно кликать по полу, дверям и персонажам. **`F10` — редактор.**

---

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org). Дважды кликни **`start.bat`** — откроется `http://localhost:8080`.

Открывать `index.html` напрямую нельзя: браузер не даст прочитать настройки и песню.

В этом режиме «Сохранить» в редакторе пишет прямо в папку проекта, токен не нужен.

## Публикация на GitHub Pages

1. Создай на github.com пустой публичный репозиторий, например `cherry-birthday`.
2. В папке проекта:
   ```
   git init -b main
   git add .
   git commit -m "Первая версия"
   git remote add origin https://github.com/ЛОГИН/cherry-birthday.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.
4. Через минуту игра будет по адресу `https://ЛОГИН.github.io/cherry-birthday/`.

Папка `одевашка лена/` (исходники из фотошопа, ~190 МБ) в репозиторий не попадает — она в `.gitignore`. На сайте лежат сжатые копии в `assets/dressup/`.

## Редактор (F10)

Нажми `F10` в любом месте игры — справа откроется панель, игра встанет на паузу.

- **Объекты на экране** можно тащить мышкой. Колесо — размер, стрелки — сдвиг на 1 пиксель (`Shift` — на 10), зелёный квадратик в углу рамки тоже меняет размер.
- **Выбранный объект** — все его поля: картинка, координаты, тексты, диалоги.
- **Настройки этой сцены** — всё, что относится к текущему экрану. **Все настройки игры** — вообще всё.
- **Картинки и звук** загружаются кнопкой «Загрузить…» прямо со своего компьютера.
- **Перейти в другое место игры** — прыжок в любую комнату, мини-игру, катсцену или финал. Там же «Все двери открыты» и сброс своего прогресса.
- **Сохранить на сайт** — отправляет правки в репозиторий. Через 1–2 минуты их увидят все.
- **Отменить правки** — вернуть всё, как на сайте.

Пока не нажато «Сохранить», правки видишь только ты. Если двое правят одновременно, ничего не затрётся: при сохранении берётся свежая версия с сайта и на неё накладывается только то, что изменил ты.

### Доступ для сохранения

В редакторе раскрой «Доступ к GitHub» и вставь токен (один раз, он хранится только в твоём браузере). Логин и репозиторий на сайте подставляются сами.

- **Владелец репозитория:** GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → *Only select repositories* → этот репозиторий → Permissions → **Contents: Read and write**. Этот токен умеет менять только этот сайт, поэтому его можно лично (не публично!) передать художникам.
- **Соавтор**, добавленный в Settings → Collaborators: classic-токен с галочкой **public_repo**.

Кнопка «Проверить доступ» скажет, всё ли в порядке.

## Что и где менять

### Героиня
Спрайт-лист **3 кадра × 4 ряда**: ряды — вниз, влево, вправо, вверх; средний кадр — «стоит». Редактор → «Героиня (спрайт-лист)» → загрузить картинку. Число кадров, порядок рядов, размер и скорость меняются там же.

### Комнаты
Фон, двери, персонаж, предметы-декорации, зона ходьбы, точка появления. Двери и персонажа можно таскать по экрану. Новая дверь или декорация — кнопка «+ Добавить» в соответствующем списке.

Диалог — список реплик. Строка, начинающаяся с `>`, — слова героини.

Порядок открытия комнат задан в `data/game.json` → `order`.

### Торт
Четыре шага, у каждого свои картинки, тексты и числа (сколько кругов мешать, сколько попаданий, ширина зелёной зоны). В редакторе есть кнопки перехода к любому шагу.

### Одевашка
В редакторе, в «Инструментах этой сцены»:
- **Добавить вещи** — открой нужную вкладку гардероба и загрузи PNG. Если картинка того же размера, что и тело (слой из фотошопа целиком), она сразу встанет на место. Иконка делается сама, её можно заменить.
- Позиция, масштаб, поворот, зеркало, слой и вид иконки — как в прошлой одевашке. По умолчанию всё стоит «как нарисовано», двигать не обязательно.
- Сколько вещей категории можно надеть разом — поле «Сколько можно надеть сразу» в категориях (верх — 2, аксессуары — 99).

### Ритм-игра
- Песни: Ритм-игра → Песни → загрузить звук, вписать название. Песня без файла показывается как «скоро…».
- Ноты подбираются автоматически по музыке. Свои ноты: F10 → «Записать ноты» → стучи по `S D K L` в ритм, `Esc` — стоп.
- Три кадра танца Сони — спрайт-лист в «Танцовщица», кадры переключаются под удары. Если танец не попадает в такт, впиши BPM песни.
- Сложности, дорожки, цвета, картинки нот — там же.

### Финал
Девочки, торт, огонёк свечи, реплики (имя + текст), финальный заголовок, музыка, салют.

## Устройство проекта

```
index.html
data/game.json     ← ВСЕ настройки: тексты, картинки, позиции, одежда
assets/            ← картинки и звук (uploads/ — загруженное через редактор)
css/               game.css · dressup.css · editor.css
js/core.js         ядро: сцены, диалоги, клавиши, прогресс
js/rooms.js        комнаты, двери, персонажи
js/kitchen.js      торт
js/dressup.js      одевашка
js/rhythm.js       ритм-игра
js/finale.js       финал
js/editor.js       редактор (F10)
js/github.js       сохранение в репозиторий
js/main.js         заставка, катсцены, запуск
tools/server.js    локальный сервер для start.bat
```

Игровой экран — 960×540 «игровых пикселей», он растягивается под окно. Координаты объекта: `x, y` — точка низ-центр картинки («ноги»), `w` — ширина; высота считается по пропорциям картинки.

Прогресс игрока (пройденные комнаты, рекорды, наряд) хранится в его браузере. Сброс — «Начать заново» на заставке.

Быстрый переход по ссылке: `?scene=room:hub`, `?scene=kitchen:2`, `?scene=dressup`, `?scene=rhythm`, `?scene=cutscene:kitchen`, `?scene=finale`; `?edit` — сразу с открытым редактором.
