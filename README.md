# 🍒 Вишнёвое приключение ко дню рождения

Игра-подарок. Пиксельный дом из четырёх комнат на одной карте: гостиная в центре, кухня слева, гардеробная сверху, музыкальная справа. Комнаты, где героиня ещё не была, затемнены; двери открываются по очереди. В каждой комнате — персонаж, диалог и мини-игра, после неё — катсцена. Когда пройдены все три, начинается финал: три девочки, торт со свечкой и салют.

**Играть:** https://richmpen.github.io/HappyBirthdayBlat/

| Комната | Персонаж | Мини-игра |
|---|---|---|
| Кухня | Аня | Торт «Красный бархат»: 8 коротких игр на время, рецепт в углу |
| Гардеробная | Лиза | Одевашка (механика CottsugDRESSUP, вишнёвое оформление) |
| Музыкальная | Соня | Ритм-игра на клавишах `S D K L` с длинными нотами |

Мир и арт мини-игр — пиксельные; интерфейс, ритм-игра и одевашка — нет.

Управление: `WASD` / стрелки — ходить, `E` — действие, мышкой можно кликать по полу и персонажам. **`F10` — редактор.**

---

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org). Дважды кликни **`start.bat`** — откроется `http://localhost:8080`.

Открывать `index.html` напрямую нельзя: браузер не даст прочитать настройки и песню.

В этом режиме «Сохранить» в редакторе пишет прямо в папку проекта, токен не нужен.

## Публикация

Сайт — это ветка `main` репозитория, GitHub Pages включён. Обновить сайт руками:

```
git add -A
git commit -m "что изменилось"
git push
```

Папка `одевашка лена/` (исходники из фотошопа, ~190 МБ) в репозиторий не попадает — она в `.gitignore`. На сайте лежат сжатые копии в `assets/dressup/`.

## Редактор (F10)

Нажми `F10` в любом месте игры — справа откроется панель, игра встанет на паузу.

- **Объекты на экране** можно тащить мышкой. Стрелки — сдвиг на 1 пиксель (`Shift` — на 10).
- **Выбранный объект** — все его поля: картинка, координаты, тексты, диалоги.
- **Инструменты этой сцены** — то, что нужно именно здесь (см. ниже).
- **Настройки этой сцены** и **Все настройки игры** — тексты, числа, картинки, звук.
- **Картинки и звук** загружаются кнопкой «Загрузить…» прямо со своего компьютера.
- **Перейти в другое место игры** — прыжок в любую комнату, мини-игру, катсцену или финал; там же «Все двери открыты» и сброс своего прогресса.
- **Сохранить на сайт** — отправляет правки в репозиторий. Через 1–2 минуты их увидят все.
- **Отменить правки** — вернуть всё, как на сайте.

Пока не нажато «Сохранить», правки видишь только ты. Если двое правят одновременно, ничего не затрётся: при сохранении берётся свежая версия с сайта и на неё накладывается только то, что изменил ты.

### Доступ для сохранения

В редакторе раскрой «Доступ к GitHub» и вставь токен (один раз, он хранится только в твоём браузере). Логин и репозиторий на сайте подставляются сами.

- **Владелец репозитория:** GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → *Only select repositories* → этот репозиторий → Permissions → **Contents: Read and write**. Этот токен умеет менять только этот сайт, поэтому его можно лично (не публично!) передать художникам.
- **Соавтор**, добавленный в Settings → Collaborators: classic-токен с галочкой **public_repo**.

Кнопка «Проверить доступ» скажет, всё ли в порядке.

## Что и где менять

### Дом
Каждая комната — прямоугольник в клетках (клетка = 16 пикселей арта), текстура стены и пола. Вся мебель — отдельные предметы:

- **Добавить предмет** — открывает палитру из набора (мебель, мелочи, двери); **Своя картинка…** — загрузить свой спрайт.
- У выбранного предмета: **Преграда** (нельзя пройти), **На полу** (ковёр — всегда под героиней), **Отразить**, **Дублировать**, **Удалить**.
- Пустое место тянет камеру. Комнаты в редакторе всегда освещены.
- Двери — список «Двери»: какие комнаты соединяет, с какой стороны, отступ вдоль стены и текст «персонаж не дома».
- Персонаж комнаты: картинка, имя, диалоги. Строка диалога, начинающаяся с `>`, — слова героини.

Порядок открытия комнат — «Все настройки игры → order».

### Героиня
Спрайт-лист **3 кадра × 4 ряда**: ряды — вниз, влево, вправо, вверх; средний кадр — «стоит». Редактор → «Героиня (спрайт-лист)» → загрузить картинку. Число кадров, порядок рядов и скорость меняются там же. Размер кадра любой — мир показывает арт с увеличением ×2.

### Торт
Рецепт (название, подпись), продукты, обманки, время на всё (`timeLimit`, 0 — без таймера) и восемь шагов. Порядок шагов — список `steps`: лишний шаг можно убрать. У каждого шага свои картинки, тексты и числа. В редакторе есть кнопки перехода к любому шагу; пока редактор открыт, время не идёт.

Чтобы сделать другой торт: поменяй название рецепта, список продуктов, цвета теста в шаге «Взбить» (`colorFrom` / `colorTo`) и картинки коржей и торта.

### Одевашка
В «Инструментах этой сцены»:
- **Добавить вещи** — открой нужную вкладку гардероба и загрузи PNG. Если картинка того же размера, что и тело (слой из фотошопа целиком), она сразу встанет на место. Иконка делается сама, её можно заменить.
- Позиция, масштаб, поворот, зеркало, слой и вид иконки — как в прошлой одевашке.
- Сколько вещей категории можно надеть разом — «Сколько можно надеть сразу» в категориях (верх — 2, аксессуары — 99).
- **Персонаж в рамке** — кнопка «Двигать персонажа мышкой»: тянешь всего персонажа по рамке, колесо меняет масштаб. Там же «Верх рамки» и «Низ рамки» — насколько рамка облегает персонажа (доля высоты картинки тела).

### Ритм-игра
- Песни: Ритм-игра → Песни → загрузить звук, вписать название. Песня без файла показывается как «скоро…».
- Ноты ставятся автоматически: игра находит темп и доли песни и ставит ноты на эту сетку. Сложность решает, какие клетки заняты (`grid`, `keep`), и сколько длинных нот (`hold`).
- Если ноты всё же чуть раньше или позже музыки — «Сдвиг звука, мс». Если игра ошиблась с темпом — впиши BPM и время первого удара у песни.
- Свои ноты: F10 → «Записать ноты» → стучи по `S D K L` в ритм (держи — будет длинная нота), `Esc` — стоп.
- Танцовщица — спрайт-лист из трёх кадров в «Танцовщица», кадры переключаются по долям.
- Значки, цвета дорожек и цвета сцены — там же. В `bg` можно загрузить свою картинку фона вместо нарисованной сцены.

### Финал
Девочки, торт, огонёк свечи, реплики (имя + текст), финальный заголовок, музыка, салют.

### Эффекты
Все эффекты сделаны в [Arcadia Effector](https://github.com/xaidan777/Arcadia-Effects): исходники лежат в `effects/*.json`, готовые спрайт-атласы — в `assets/fx/`. Чтобы изменить эффект: открой его JSON в Arcadia Effector (Import), поправь, экспортируй атлас PNG и загрузи его в редакторе игры в «Эффекты» (там же число колонок, рядов, кадров и скорость — они есть в Meta JSON редактора эффектов).

## Устройство проекта

```
index.html
data/game.json     ← ВСЕ настройки: тексты, картинки, позиции, одежда, рецепт
assets/            ← картинки и звук (uploads/ — загруженное через редактор)
  world/           стены, полы, мебель, двери (набор Top-Down Retro Interior)
  fx/              атласы эффектов
effects/           исходники эффектов для Arcadia Effector
css/               game.css · dressup.css · editor.css
js/core.js         ядро: сцены, диалоги, клавиши, прогресс, эффекты
js/world.js        дом: комнаты, двери, столкновения, камера
js/kitchen.js      торт
js/dressup.js      одевашка
js/rhythm.js       ритм-игра
js/finale.js       финал
js/editor.js       редактор (F10)
js/github.js       сохранение в репозиторий
js/main.js         заставка, катсцены, запуск
tools/server.js    локальный сервер для start.bat
```

Игровой экран — 960×540 «игровых пикселей», он растягивается под окно. В доме и на кухне координаты предметов — в пикселях арта, точка «низ-центр» картинки.

Прогресс игрока (пройденные комнаты, рекорды, наряд) хранится в его браузере. Сброс — «Начать заново» на заставке.

Быстрый переход по ссылке: `?scene=world`, `?scene=room:kitchen`, `?scene=kitchen:3`, `?scene=dressup`, `?scene=rhythm`, `?scene=cutscene:kitchen`, `?scene=finale`; `?edit` — сразу с открытым редактором.

Мебель и интерьер — бесплатный набор «Top-Down Retro Interior».
