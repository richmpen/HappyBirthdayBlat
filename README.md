# 🍒 Вишнёвое приключение ко дню рождения

Игра-подарок. Начинается с главного меню (рисованная Лена, торт «22» с горящими свечками, мигающие звёздочки). Дальше — пиксельный дом из четырёх комнат на одной карте: гостиная в центре, кухня слева, гардеробная сверху, музыкальная справа. Комнаты, где героиня ещё не была, затемнены; двери открываются по очереди. В каждой комнате — персонаж, диалог и мини-игра, после неё — катсцена (у гардеробной и музыкальной — видео по кругу). Когда пройдены все три, начинается концовка: Лиза, Аня и Андрей приходят к Лене, поздравляют, она задувает свечку — и салют.

Кнопка-цветочек «Галерея» (в меню и в левом нижнем углу везде) появляется, когда игра пройдена: все катсцены и арт начала и концовки.

Игра растянута на весь экран без рамок; если пропорции окна не 16:9, по краям виден вишнёвый фон.

**Играть:** https://richmpen.github.io/HappyBirthdayBlat/

| Комната | Персонаж | Мини-игра |
|---|---|---|
| Кухня | Аня | Торт «Красный бархат»: 8 коротких игр на время, рецепт в углу |
| Гардеробная | Лиза | Одевашка (механика CottsugDRESSUP, вишнёвое оформление) |
| Музыкальная | Андрей | Ритм-игра на клавишах `S D K L` с длинными нотами |

Мир и арт мини-игр — пиксельные; интерфейс, ритм-игра и одевашка — нет.

Управление: `WASD` / стрелки — ходить, `E` — действие, мышкой можно кликать по полу и персонажам. **`F10` — редактор, `F11` — слои.** Кнопок редактора в игре не видно — только эти клавиши.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org). Дважды кликни **`start.bat`** — откроется `http://localhost:8080`.

Открывать `index.html` напрямую нельзя: браузер не даст прочитать настройки и песню.

**Это и есть главный способ править игру.** В этом режиме «Сохранить» в редакторе пишет правки в папку проекта и сам отправляет их на GitHub обычным `git` — тем входом в GitHub, который уже есть на компьютере. Ничего вводить не нужно; через 1–2 минуты правки видны на сайте.

При запуске `start.bat` сам забирает с GitHub свежую версию. Если интернета нет, правки остаются на компьютере и уйдут при следующем «Сохранить».

## Публикация

Сайт — это ветка `main` репозитория, GitHub Pages включён. Обновить сайт руками:

```
node tools/bump-build.js     (если менялись файлы в js/ или css/)
git add -A
git commit -m "что изменилось"
git push
```

`bump-build.js` обновляет номер версии в `index.html`. По нему игра сама замечает, что на сайте вышла новая версия, и перезагружается на неё; номер виден в шапке редактора. Если всё же видишь старую версию — нажми `Ctrl+F5`.

Папка `одевашка лена/` (исходники из фотошопа, ~190 МБ) в репозиторий не попадает — она в `.gitignore`. На сайте лежат сжатые копии в `assets/dressup/`.
Так же и `Файлы/` (новые пиксельные спрайты: сжатые копии в `assets/kitchen/ing`, `assets/kitchen/tools`, `assets/sprites`) и `ритм игра/` (макет ритм-игры, ~26 МБ): на сайте — сжатые копии в `assets/rhythm/`, песни в `assets/audio/`, шрифты в `assets/fonts/`.
И `общий визуал/` (главное меню, концовка, видео-катсцены, музыка, ~250 МБ): сжатые копии в `assets/menu/`, `assets/finale/`, `assets/gallery/`, `assets/cutscenes/` (видео 1080p без звука), `assets/audio/bgm-*.mp3` и `finale.mp3` (выровнены по громкости, тишина по краям обрезана), шрифты Gooseberry и Bryndan Write — в `assets/fonts/`.

## Редактор (F10)

Нажми `F10` в любом месте игры — справа откроется панель, игра встанет на паузу.

- **Объекты на экране** можно тащить мышкой. Стрелки — сдвиг на 1 пиксель (`Shift` — на 10).
- **Выбранный объект** — все его поля: картинка, координаты, тексты, диалоги.
- **Инструменты этой сцены** — то, что нужно именно здесь (см. ниже).
- **Настройки этой сцены** и **Все настройки игры** — тексты, числа, картинки, звук.
- **Картинки и звук** загружаются кнопкой «Загрузить…» прямо со своего компьютера.
- **Перейти в другое место игры** — прыжок в любую комнату, мини-игру, катсцену или финал; там же «Все двери открыты» и сброс своего прогресса.
- **Сохранить на сайт** — отправляет правки в репозиторий. Через 1–2 минуты их увидят все. Работает сам, если игра открыта через `start.bat`.
- **Отменить правки** — вернуть всё, как на сайте.

Пока не нажато «Сохранить», правки видишь только ты. Если двое правят одновременно, ничего не затрётся: при сохранении берётся свежая версия с сайта и на неё накладывается только то, что изменил ты.

### Слои (F11)
`F11` открывает редактор сразу на списке слоёв сцены: все картинки, сверху — то, что выше. У каждой: 👁 спрятать, ▲▼ слой выше/ниже, 🖼 заменить картинку (из набора — всех картинок проекта — или своей), ⧉ дублировать, ✕ удалить. Второй `F11` закрывает редактор. Набор картинок — `data/assets.json`, его обновляют `node tools/assets-list.js` и `bump-build.js` (и сам `start.bat` при сохранении новых файлов).

### Сохранять может любой
Чтобы любой, кто открыл сайт, мог поправить игру (F10 / F11) и нажать «Сохранить», владелец один раз встраивает ключ: редактор → «Как сохранить на сайт» → вставить fine-grained токен (только этот репозиторий, *Contents: Read and write*) → **«🌍 Разрешить сохранять всем»**. Ключ ложится в `data/share.json` (в запутанном виде, чтобы GitHub не счёл его утечкой). Этот ключ может достать любой посетитель — поэтому токен только на этот репозиторий; история правок остаётся в git. Забрать доступ — кнопка «🚫 Запретить» или удалить токен на GitHub.

### Сохранение прямо с сайта своим ключом (необязательно)

Если игра открыта через `start.bat`, этот раздел не нужен. Он для тех, у кого нет папки с игрой и кто правит прямо на сайте: сам сайт GitHub Pages ничего записать не может, поэтому нужен ключ. В редакторе раскрой «Как сохранить на сайт» → «Сохранять прямо с сайта» и вставь токен (один раз, он хранится только в твоём браузере). Логин и репозиторий подставляются сами.

- **Владелец репозитория:** GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → *Only select repositories* → этот репозиторий → Permissions → **Contents: Read and write**. Этот токен умеет менять только этот сайт, поэтому его можно лично (не публично!) передать художникам.
- **Соавтор**, добавленный в Settings → Collaborators: classic-токен с галочкой **public_repo**.

Кнопка «Проверить доступ» скажет, всё ли в порядке.

## Что и где менять

### Дом
Каждая комната — прямоугольник в клетках (клетка = 16 пикселей арта), текстура стены и пола. Вся мебель — отдельные предметы:

- **Добавить предмет** — открывает палитру из набора (мебель, мелочи, двери); **Своя картинка…** — загрузить свой спрайт.
- У выбранного предмета: **Преграда** (нельзя пройти), **На полу** (ковёр — всегда под героиней), **Отразить**, **Дублировать**, **Удалить**.
- Пустое место тянет камеру. Комнаты в редакторе всегда освещены.
- Двери — список «Двери»: какие комнаты соединяет, с какой стороны, отступ вдоль стены и текст «персонаж не дома».
- Персонаж комнаты (`npc`): картинка, имя, диалог — после него начинается мини-игра. `danceImg` — во что он превращается после разговора (Андрей танцует, с диско-вспышкой), `danceWait` — сколько секунд он танцует до начала игры.
- Другие персонажи (`chars`, кнопка «🐾 Добавить персонажа»): кошка Лиззи в гостиной, собака Сонечка у Лизы — с ними просто разговор.
- «🖼 Заменить картинку…» у любого предмета или персонажа — выбрать из набора всех картинок проекта; колесо или уголок — размер, «1:1» — исходный размер, «▲ / ▼ слой».

### Диалоги-новеллы
Диалог персонажа — список фраз. У фразы: кто говорит (персонаж, Лена или любое имя), текст, **спрайт** слева (как в новелле; остаётся до следующей фразы со спрайтом; несколько кадров — меняются раз в `spriteEvery` секунд, как SOS у Андрея) и **картинка** на весь экран за окном диалога — только на этой фразе (фраза с картинкой без текста — просто картинка, клик — дальше). Когда говорит не этот персонаж, его спрайт темнеет и чуть уменьшается к низу. В редакторе у персонажа: «▶ Проиграть диалог», «+ Фраза», «+ Картинка», у каждой фразы ↑ ↓ + ✕. Спрайты лежат в `assets/novel/`, картинки — в `assets/cutscenes/`.

Порядок открытия комнат — «Все настройки игры → order».

### Героиня
Спрайт-лист **3 кадра × 4 ряда** (сейчас — `assets/sprites/lena_walk.png`, кадр 34×48). Какой ряд какое направление — `rowDown`, `rowLeft`, `rowRight`, `rowUp`; кадр «стоит» — `idleFrame`; порядок кадров шага — `walk` (например `[1, 0, 2, 0]`). Редактор → «Героиня (спрайт-лист)» → загрузить картинку. Размер кадра любой — мир показывает арт с увеличением ×2.

### Торт
Новые картинки кухни — `assets/kitchen/v2/` (из папок `кухня/` и `кухня оставшееся/`). «Отмерить»: продукт стоит над стаканом и при нажатии наклоняется на месте (`tilt`); у продукта `kind`: `liquid` — льётся струйкой, `dry` — сыплется крупинками. Зелёная зона нарисована на самом стакане (`drawZone: false`). «Взбить» — водить мышкой туда-сюда над миской. Продукту можно задать ширину `w` (кефир уменьшен).

Рецепт (название, подпись), продукты, обманки, время на всё (`timeLimit`, 0 — без таймера) и восемь шагов. Порядок шагов — список `steps`: лишний шаг можно убрать. У каждого шага свои картинки, тексты и числа. В редакторе есть кнопки перехода к любому шагу; пока редактор открыт, время не идёт.

Миска и тесто: у шага «Взбить» в `stages` — картинки теста от светлого к красному (крутятся вместе с венчиком), `rim` у миски — толщина бортика. У продукта в шаге «Отмерить» можно указать свою картинку (`img`), например банку с ложкой.

Чтобы сделать другой торт: поменяй название рецепта, список продуктов, цвета теста в шаге «Взбить» (`colorFrom` / `colorTo`) и картинки коржей и торта.

### Одевашка
В «Инструментах этой сцены»:
- **Добавить вещи** — открой нужную вкладку гардероба и загрузи PNG. Если картинка того же размера, что и тело (слой из фотошопа целиком), она сразу встанет на место. Иконка делается сама, её можно заменить.
- Позиция, масштаб, поворот, зеркало, слой и вид иконки — как в прошлой одевашке.
- Сколько вещей категории можно надеть разом — «Сколько можно надеть сразу» в категориях (верх — 2, аксессуары — 99).
- **Персонаж в рамке** — кнопка «Двигать персонажа мышкой»: тянешь всего персонажа по рамке, колесо меняет масштаб. Там же «Верх рамки» и «Низ рамки» — насколько рамка облегает персонажа (доля высоты картинки тела).

### Ритм-игра
- «К празднику» появляется уже после первой пройденной песни.
- Песни: Ритм-игра → Песни → загрузить звук, вписать название. Песня без файла показывается как «скоро…».
- Ноты ставятся автоматически: игра находит темп и доли песни и ставит ноты на эту сетку. Сложность решает, какие клетки заняты (`grid`, `keep`), и сколько длинных нот (`hold`).
- Если ноты всё же чуть раньше или позже музыки — «Сдвиг звука, мс». Если игра ошиблась с темпом — впиши BPM и время первого удара у песни.
- Свои ноты: F10 → «Записать ноты» → стучи по `S D K L` в ритм (держи — будет длинная нота), `Esc` — стоп.
- Оформление — неоновая сцена из макета (исходники в папке `ритм игра/`, сжатые копии — `assets/rhythm/`). Всё рисуется в координатах макета 1672×941 и растягивается на экран.
- Картинки сцены — списки «Сцена: задний план» (`back`), «Персонажи» (`band`), «Сцена: перед персонажами» (`front`) и «Сцена: поверх нот» (`overlay`). Любую картинку можно тащить мышкой, колесо — размер. Точка картинки — низ-центр, или `pivot` (доли ширины и высоты).
- Анимация картинки — поле `anim`: `beam` — прожектор качается вокруг `pivot` (у прожекторов он в верхнем «носике»), `glow` — свечение дышит в такт, `pulse` — вспышка на каждую долю, `sway` — покачивание, `twinkle` — мерцание.
- Персонажи — список кадров (`frames`), кадр меняется на каждую долю песни (`every` — через сколько долей).
- Фразы (`phrases`) всплывают по очереди во время игры и на каждой вспышке комбо.
- Звёзды в углу загораются за долю идеального счёта (`starAt`), счёт и кнопки клавиш — шрифтом Game of Squids, русские надписи — Glina Script (`assets/fonts/`).
- Кнопки дорожек: X каждой дорожки — в «Дорожки», высота — «Линия попадания», картинки колец — `ring` / `ringFill`. Свою картинку ноты можно загрузить в `img` дорожки.

### Главное меню
Собрано из слоёв макета `общий визуал/начало главное меню/` и рисуется в его координатах (3492×1640), вписанных в экран; сверху и снизу — полосы рамки.
- Слои — «Главное меню → Макет → Слои картинки» (снизу вверх). У слоя: `anim` — `drift`, `glow`, `sway`, `breathe`, `slosh`, `peek`, `float`, `swing`, `hop`; `enter` — как появляется (`left`, `up`, `drop`, `pop`, `fade`); `alpha`.
- Огоньки свечей «22» (`candles`), большие искорки (`sparkles`), мигающие звёздочки (`stars`), плашка подсказок (`pill`, фразы — `hints`), кнопки (`buttons`), цветочки звука и галереи (`bell`, `gallery`). Всё можно тащить мышкой в редакторе.
- Кнопки: «Начать» → после первой комнаты «Продолжить» и «Начать заново», после всех комнат ещё «К празднику». Стрелки ↑↓ — выбор, E/Enter — нажать.

### Музыка
«Музыка игры» (`music`): песни из `playlist` играют по очереди, соседние плавно перетекают (`crossfade`, секунд). Играет везде, кроме ритм-игры (там свои песни) и концовки (своя музыка). После ритм-игры плейлист продолжает с того же места. Колокольчик в меню выключает весь звук.

### Катсцены
У комнаты `cutscene`: `video` — видео по кругу, пока игрок не нажмёт E или не кликнет (`img` — картинка-заставка, пока видео грузится); либо просто `img`.

### Галерея
`gallery.items` — карточки: `name`, `img` (или `video` + `thumb`), `text`, `unlock` — когда открывается: пусто — сразу, `kitchen` / `dressup` / `rhythm` — пройдена комната, `all` — все комнаты, `finale` — начался праздник, `wish` — свечка задута. `hint` — подсказка на закрытой карточке. Пока галерея открыта, игра на паузе.

### Концовка
Макет `общий визуал/концовка/`, координаты 3492×1640.
1. Комната и Лена; Лиза, Аня, Андрей (`girls`, по порядку) выходят из полумрака по одному (`spotlight`, `shadeColor`, свет над гостем — `light`).
2. Реплики `dialog` (имя + текст), над говорящим — сердечко.
3. Зажигается свечка (`candle`), реплика `wish` — нужно нажать на свечку (или E).
4. Свечка гаснет, экран плавно темнеет (`dark`, цвет из 11.png), появляются надписи, сердечко, кнопка «в главное меню» (`end`) и салют.
Шарики (`balloons`) покачиваются всё время. Музыка — `music`. В редакторе есть кнопки «Комната / Загадай желание / Финальный экран / Проиграть сначала».

Фон `assets/finale/bg.webp` сделан из `1.png` — пустой комнаты; Лена видна сразу, Лиза, Аня и Андрей появляются по очереди, шарики (отдельные картинки 2–6.png) летают вверх-вниз. Поменял `1.png` — пережми его в `bg.webp` (1921×902), иначе в игре останется старый.

### Эффекты
Все эффекты сделаны в [Arcadia Effector](https://github.com/xaidan777/Arcadia-Effects): исходники лежат в `effects/*.json`, готовые спрайт-атласы — в `assets/fx/`. Чтобы изменить эффект: открой его JSON в Arcadia Effector (Import), поправь, экспортируй атлас PNG и загрузи его в редакторе игры в «Эффекты» (там же число колонок, рядов, кадров и скорость — они есть в Meta JSON редактора эффектов).
